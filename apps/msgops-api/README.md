## Description

Msgops API was developed using [Nest](https://github.com/nestjs/nest), a TypeScript framework.

## Installation

We use yarn on this project, if you don't have it installed please check [instructions here](https://yarnpkg.com/getting-started/install).

```bash
$ yarn install
```

## Running the app

```bash
# development
$ yarn start

# watch mode
$ yarn start:dev

# production mode
$ yarn start:prod
```

## Test

```bash
# unit tests
$ yarn test

# e2e tests
$ yarn test:e2e

# test coverage
$ yarn test:cov
```

## Docs

You can check documentation on your browser after start the server on http://localhost:5001/api-docs/
